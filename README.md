# Niyyah website (v4)

A static seven-page site: Home, Journey, Shop, Plan, Packages, About, and a Thank-you page for buyers.
Open index.html in a browser to view it.

To put it online free with GitHub Pages: upload everything in this folder to a GitHub repository,
then go to Settings > Pages > Deploy from a branch (main, root).

Prices and product links come from products/catalog.py in Claude's workspace; ask Claude to rebuild
after a listing goes live so its button points to the Etsy listing.
